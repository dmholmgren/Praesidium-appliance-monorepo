⚠ Emergency Shell Access

Each tenant has a break-glass administrator account accessible only via shell on WEB-01. This account is not exposed through the web UI and is intended for use only when all other authentication methods (LDAP, Azure AD, native auth) are unavailable.

  • • Access requires SSH to main-prd-web-01
  • • Contact your platform administrator to request emergency access
  • • All break-glass sessions are logged and audited
  • • Account has full tenant admin rights — no cross-tenant access
