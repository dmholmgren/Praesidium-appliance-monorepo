Install the Windows Agent

Copy the agent files to the Timeslips Windows Server VM, then right-click ts_sync_agent_setup.bat and choose Run as administrator. No terminal required.

1. Copy agent files to C:\Praesidium\TSAgent\ on the Timeslips VM
2. Right-click ts_sync_agent_setup.bat → Run as administrator
3. When prompted for the API key, enter: {{ api_key }}
4. When prompted for the database path, enter: {{ config.fb_database or 'your .fdb path' }}
5. Setup will run an initial sync and schedule automatic syncs
